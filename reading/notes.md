# 14篇VLA论文：五行速读与中文对比

整理日期：2026-10-21。依据14份固定版本原文；版本固定为所用版本，后续代码更新与原论文能力分别理解。下文页码均为PDF阅读器从1起算的页序号。

阅读方法：先看对比表建立位置，再看每篇五行；理解后到“证据”所列图表核对。各论文数据、机器人、评分和适配预算不同，表中不做跨论文成功率排名。“边界”区分论文已有局限与对结果适用范围的阅读判断，不代表作者没有考虑所有相关问题。

## 一、先把14篇放进四个层次

| 层次 | 对应论文 | 先回答的问题 |
| --- | --- | --- |
| 数据基础与跨机器人验证 | Open X-Embodiment / RT-X | 能从哪些机器人的经验学习？ |
| 通用机器人策略 | RT-2、OpenVLA、Octo、π₀、π₀.₅、SmolVLA | 怎样将观察与任务要求映射为动作？ |
| 动作建模与适配方法 | ACT、Diffusion Policy、FAST、OpenVLA-OFT、LoRA | 动作怎么表示、生成，参数怎么更新？ |
| 任务与可靠性评测 | LIBERO、LIBERO-Plus | 在什么条件下、用什么标准判断有效？ |

分类是阅读索引。ACT、Diffusion Policy和OpenVLA-OFT本身也产生机器人策略；FAST主要是动作编码方法，LoRA是通用参数适配工具，两个LIBERO是基准。

## 三、用六条联系串起来

1. **RT-2与OpenVLA**：都可用动作token连接视觉语言模型和机器人控制。OpenVLA是公开可适配底座的重要代表；这里是方法联系，不表示OpenVLA由RT-2权重初始化。
2. **OpenVLA与OpenVLA-OFT**：后者确实以OpenVLA为底座，研究下游适配时如何改解码、动作表示和目标函数。
3. **Open X-Embodiment与Octo／OpenVLA**：前者提供异构机器人数据资源，后两者各自筛选、混合数据并训练自己的策略。
4. **Diffusion Policy、Octo与π₀**：前两者涉及扩散动作生成；π₀用flow matching动作专家。扩散与flow matching都是生成式连续建模路线，但学习目标和生成过程不同。
5. **π₀、FAST与π₀.₅**：FAST提出压缩动作token，π₀-FAST是相应策略变体；π₀.₅结合FAST预训练、flow动作后训练和高层语义任务。不能概括成“所有后续模型都改用同一种动作输出”。
6. **LoRA、LIBERO与LIBERO-Plus**：LoRA回答“怎样更新参数”；两个基准回答“怎样评测”。它们可以与模型组合，不能与模型本体按同一指标排一个总名次。

### 01 RT-2

所用版本：2307.15818v1，26页。[原论文PDF](https://arxiv.org/pdf/2307.15818v1) · [原文来源](https://arxiv.org/abs/2307.15818v1)

- **问题：** 机器人演示覆盖的物体、说法和场景有限，怎样将网络图文知识用于实际控制？
- **输入 → 输出：** 相机图像＋语言指令 → 一步动作的离散token → 解码为位移、旋转、夹爪与终止信号。
- **核心改动：** 在已有视觉语言模型上，将动作编码为现有词表中的token，并混合机器人数据与网络图文数据微调；动作离散化本身继承RT-1。
- **证据：** Figure 4（p.8）与Table 4（p.23）：对应评测中，RT-1未见场景平均32%，RT-2-PaLI-X为62%，已见任务表现相近；Figure 6b（p.10）检查规模和训练配方。
- **边界：** §5（p.11）和Figure 9（p.23）：语义迁移没有自动带来全新运动技能，陌生物体动力学仍会导致失败；大模型控制延迟较高。

### 02 OpenVLA

所用版本：2406.09246v3，37页。[原论文PDF](https://arxiv.org/pdf/2406.09246v3) · [原文来源](https://arxiv.org/abs/2406.09246v3)

- **问题：** 如何获得公开、可适配的通用机器人策略，并降低使用大型闭源VLA的门槛？
- **输入 → 输出：** 原版单张相机图像＋语言指令 → 自回归生成一步离散动作token → 连续控制量。
- **核心改动：** 基于Prismatic-7B VLM，融合DINOv2和SigLIP视觉特征，在多机器人示范上训练，并提供LoRA适配与量化评测流程。
- **证据：** Figure 5（p.9）展示新机器人适配；Table 1（p.10）中LoRA接近全参数适配。注意该节脚注使用较小数据混合、仅SigLIP视觉骨干的模型变体；主架构见Figure 2（p.4）。
- **边界：** §6（p.11）：原版仅支持单图像，动作生成吞吐量限制高频控制，可靠性仍有提升空间；后续OFT的多相机能力不能倒算为原版能力。

### 03 π₀

所用版本：2410.24164v4，17页。[原论文PDF](https://arxiv.org/pdf/2410.24164v4) · [原文来源](https://arxiv.org/abs/2410.24164v4)

- **问题：** 如何结合视觉语言知识和连续动作生成，支持多机器人、高频且灵巧的操作？
- **输入 → 输出：** 相机图像＋语言指令＋机器人状态 → 条件flow matching生成连续动作块 → 执行控制。
- **核心改动：** 在预训练VLM上加入机器人动作专家，以flow matching建模连续动作分布，并采用多机器人数据预训练与任务后训练。
- **证据：** Figure 7（p.8）、11（p.10）、13（p.11）分别比较直接使用、不同示范量适配和复杂任务后训练，整体支持预训练迁移的收益；模型机制见Figure 3（p.4）。
- **边界：** §VII（p.11–12）：部分任务仍不可靠，预训练数据配比及跨任务、跨机器人迁移的边界尚未充分解释；复杂任务结果需区分是否经过后训练。

### 04 Open X-Embodiment / RT-X

所用版本：2310.08864v9，12页。[原论文PDF](https://arxiv.org/pdf/2310.08864v9) · [原文来源](https://arxiv.org/abs/2310.08864v9)

- **问题：** 各实验室的数据被机器人、任务和格式分隔，跨机器人经验能否共享并产生正迁移？
- **输入 → 输出：** 不同机器人的示范 → 标准化数据接口；RT-X策略接收图像＋指令 → 离散末端动作。
- **核心改动：** 建立跨机构、多机器人数据集合与统一格式，并用RT-1-X、RT-2-X检验跨机器人共同训练；数据集合与模型系列要分开理解。
- **证据：** Figure 4、5（p.5–6）通过目标机器人数据与跨机器人共同训练的对照展示正迁移；Figure 2（p.3）和Figure 3（p.4）分别说明数据与模型。
- **边界：** §VI（p.6–7）：实验没有覆盖感知和执行方式差异极大的机器人；格式标准化不等于所有动作语义完全相同，也不等于任意新机器人即插即用。

### 05 Octo

所用版本：2405.12213v2，17页。[原论文PDF](https://arxiv.org/pdf/2405.12213v2) · [原文来源](https://arxiv.org/abs/2405.12213v2)

- **问题：** 怎样用一个公开通用策略适应不同相机、任务描述和动作空间，并以少量目标数据迁移？
- **输入 → 输出：** 图像／可选状态＋语言指令或目标图像 → Transformer表征 → 扩散头输出连续动作块。
- **核心改动：** 用模块化输入tokenizer、Transformer和可替换读出头处理异构接口，在约80万条OXE轨迹上训练；主体并非大型VLM语言解码器。
- **证据：** Table I（p.7）中预训练后微调优于从头训练；Table II（p.7）检验结构与数据选择；Figure 5（p.6）报告直接使用结果，架构见Figure 2（p.3）。
- **边界：** §V（p.8）：腕部相机和语言条件的利用仍受数据覆盖影响；支持新接口的适配机制，不代表对所有新接口都可零样本控制。

### 06 FAST

所用版本：2501.09747v1，19页。[原论文PDF](https://arxiv.org/pdf/2501.09747v1) · [原文来源](https://arxiv.org/abs/2501.09747v1)

- **问题：** 逐时间、逐维度分桶会产生冗长且高度相关的动作token，怎样改善高频动作序列的学习？
- **输入 → 输出：** 连续动作块 → DCT频域变换、量化、BPE压缩 → token序列；解码后重建连续动作块。
- **核心改动：** 提出基于时序压缩的动作tokenizer；FAST+是通用tokenizer，π₀-FAST是使用该编码训练的策略，三者不应混称。
- **证据：** Figure 6（p.8）显示编码选择影响高频动作学习，Figure 11（p.10）结合Figure 1支持大规模训练效率收益；编码流水线见Figure 4（p.5）。
- **边界：** §VI-E与§VII（p.9–11）：论文的最高约5倍改善针对训练时间；自回归推理仍可能比连续生成版本慢，编码压缩也存在精度与长度取舍。

### 07 π₀.₅

所用版本：2504.16054v1，19页。[原论文PDF](https://arxiv.org/pdf/2504.16054v1) · [原文来源](https://arxiv.org/abs/2504.16054v1)

- **问题：** 如何让机器人在未参与训练的真实家庭中执行多阶段整理任务？
- **输入 → 输出：** 图像＋任务指令＋机器人状态 → 高层子任务文字 → 条件连续动作块。
- **核心改动：** 在π₀路线加入异构任务共同训练：先用FAST离散动作和多源语义任务预训练，再通过后训练学习flow动作专家，并联合高层子任务推断。
- **证据：** Figure 7（p.8）报告新家庭任务进度；Figure 10、11（p.10）显示跨机器人数据移除造成退步，网络数据贡献随测试类型变化，并非每项移除都显著；配方见Figure 3（p.4）。
- **边界：** §VI（p.11–12）：陌生把手、遮挡和高层子任务分心仍会造成失败；长期记忆与复杂指令有限，所测新家庭并不等于任意家庭都可靠。

### 08 SmolVLA

所用版本：2506.01844v1，24页。[原论文PDF](https://arxiv.org/pdf/2506.01844v1) · [原文来源](https://arxiv.org/abs/2506.01844v1)

- **问题：** 如何降低VLA训练和部署成本，并利用低成本机器人社区数据？
- **输入 → 输出：** 多路图像＋语言指令＋状态 → 小型VLM特征 → flow动作专家生成连续动作块，可异步执行。
- **核心改动：** 组合约450M参数模型、VLM层裁减、轻量动作专家和社区数据，并将动作预测与执行解耦。
- **证据：** Table 2–4（p.11）显示小模型在所测仿真与实机任务中有竞争力；Figure 5（p.12）显示异步执行缩短任务时间，但排序项成功率下降；结构见Figure 1（p.1），消融见Table 6–13（p.13–14）。
- **边界：** §5.1（p.14–15）：原版社区预训练主要来自SO100，规模与机器人多样性有限；适配其他平台的结果不能概括成任意平台零样本可用。

### 09 OpenVLA-OFT

所用版本：2502.19645v2，24页。[原论文PDF](https://arxiv.org/pdf/2502.19645v2) · [原文来源](https://arxiv.org/abs/2502.19645v2)

- **问题：** 原版OpenVLA动作生成较慢，怎样提高下游适配效果和控制效率？
- **输入 → 输出：** LIBERO配置：主相机＋腕部相机＋语言＋状态 → 一次前向并行回归8步连续动作块。
- **核心改动：** 将并行解码、动作分块、连续动作表示和L1目标组成OFT微调配方；FiLM语言调制属于可选OFT+扩展。
- **证据：** Figure 2（p.3）看设计选择；Table I、II（p.6）比较组件与速度，Table IV（p.17）核对配置；论文对应协议的LIBERO均值由76.5%到97.1%。
- **边界：** §VIII（p.10）：多种同样合理的动作选择可能不易用L1刻画；预训练阶段能否同样获益尚未证明，语言依赖也可能不一致；吞吐提升不等于整回合等倍提速。

### 10 LIBERO

所用版本：2306.03310v2，44页。[原论文PDF](https://arxiv.org/pdf/2306.03310v2) · [原文来源](https://arxiv.org/abs/2306.03310v2)

- **问题：** 怎样可控地研究机器人终身学习中，物体、空间关系和行为知识的迁移？
- **输入 → 输出：** 任务描述、场景与目标条件、专家示范 → 训练／评测协议 → 成功率及终身学习指标。
- **核心改动：** 构建程序化任务生成与多种任务集，将不同知识迁移因素分开，并提供演示和统一实验接口。
- **证据：** §5.2（p.7–10）显示架构与算法选择会改变迁移和遗忘表现，说明不能只比较单一累计分数；任务划分见Figure 1、§4.2（p.2、5），指标见§5.1与Figure 3（p.6–7）。
- **边界：** §7（p.10）：仿真任务存在范围限制；原论文终身学习指标与后续VLA单策略成功率并非同一协议，高分也不能证明真实世界可靠。

### 11 LIBERO-Plus

所用版本：2510.13626v3，32页。[原论文PDF](https://arxiv.org/pdf/2510.13626v3) · [原文来源](https://arxiv.org/abs/2510.13626v3)

- **问题：** VLA在常规基准得分很高，面对视角、布局、光照和图像退化等变化时是否仍然可靠？
- **输入 → 输出：** 原任务＋七类受控扰动 → 策略闭环执行 → 分条件成功率、组合扰动和输入依赖诊断。
- **核心改动：** 在LIBERO上系统构造扰动，结合单因素、组合因素及视觉／语言干预，分析高分背后的脆弱性。
- **证据：** Table 1（p.3）展示视角、初态等变化下的明显退步；§3–5（p.3–8）的干预和组合分析进一步诊断依赖关系；基准与噪声参数见Table 2、5（p.9、15）。
- **边界：** 结论受所测任务、模型与扰动定义约束；对指令改写不敏感本身不足以证明理解指令，需结合移除／替换目标等诊断；本身不是万能鲁棒训练算法。

### 12 ACT

所用版本：2304.13705v1，18页。[原论文PDF](https://arxiv.org/pdf/2304.13705v1) · [原文来源](https://arxiv.org/abs/2304.13705v1)

- **问题：** 低成本硬件上的精细操作容易出现误差累积，如何从少量演示学到协调、连贯的动作？
- **输入 → 输出：** 相机图像＋关节状态 → CVAE与Transformer预测连续动作块 → 时间集成得到执行动作。
- **核心改动：** 组合动作分块和时间集成，使用CVAE表示演示行为变化；原版控制输入不以自由语言指令为核心。
- **证据：** Figure 8与§VI（p.9–10）的消融支持动作分块和时间集成在所测任务中的作用；Table I、II（p.8）比较任务表现；结构和执行见Figure 4、5（p.4）。
- **边界：** §VII（p.10）：仍受演示覆盖与感知条件影响；在少数任务上数据高效，不等于具有通用语义或任意任务泛化能力。

<a id="paper-13"></a>

### 13 Diffusion Policy

所用版本：2303.04137v5，19页。[原论文PDF](https://arxiv.org/pdf/2303.04137v5) · [原文来源](https://arxiv.org/abs/2303.04137v5)

- **问题：** 同一观察可能存在多种合理动作，如何稳定建模复杂连续动作分布并生成动作序列？
- **输入 → 输出：** 图像／状态等观察历史 → 条件去噪生成连续动作序列 → 执行其中一段并滚动重规划。
- **核心改动：** 用条件扩散表示策略，结合视觉条件和滚动时域控制；原版不以互联网预训练VLM与自由语言控制为前提。
- **证据：** §4.1（p.4–5）展示多峰行为，§5.4（p.8–9）消融说明生成与控制设计影响表现；§5.2（p.7）交代评分，Figure 2（p.3）区分生成与执行区间。
- **边界：** §9（p.13）：仍依赖示范分布；迭代采样带来延迟，生成长度与实际执行长度需要取舍；动作分布表达能力不保证开放世界语义能力。

<a id="paper-14"></a>

### 14 LoRA

所用版本：2106.09685v2，26页。[原论文PDF](https://arxiv.org/pdf/2106.09685v2) · [原文来源](https://arxiv.org/abs/2106.09685v2)

- **问题：** 大模型全参数适配的可训练参数与优化器成本高，如何减少需要更新和保存的参数？
- **输入 → 输出：** 预训练权重W₀＋目标任务数据 → 学习低秩增量BA → 保存适配参数或合并为W₀＋BA。
- **核心改动：** 冻结所适配的原权重，以两个小矩阵表示权重更新；它是一种参数化方法，不规定机器人动作表示或执行机制。
- **证据：** §5（p.5–8）显示在所测NLP任务中，少量适配参数可达到接近或优于全参数微调的结果；§7.1–7.2（p.10）检验适配位置与rank；机制见Figure 1、§4（p.1、4–5）。
- **边界：** 原论文实验主要是语言模型，不能直接推断VLA性能与显存；rank和适配位置需验证，底座权重及训练激活仍需内存，VLA动作头等模块也可能要额外训练和保存。

## 五、汇报前最容易混淆的八件事

| 容易混淆 | 应当怎样理解 |
| --- | --- |
| 动作token与自然语言指令 | 前者编码控制量，后者描述任务；统一成序列不代表二者语义相同。 |
| 一步动作的多个维度与多步动作块 | RT-2主设置的8项内容对应一步控制；OFT的8步块对应未来8个时刻。 |
| 连续动作与单次生成 | π₀用连续动作但仍迭代生成；OFT则可一次前向直接回归动作块。 |
| 预测长度、执行长度与采样迭代数 | 三者分别回答“算多远”“先做多少”“生成时迭代几次”，不应混用。 |
| FAST训练加速与推理加速 | 原文最高约5倍指训练时间；自回归解码仍可能成为推理瓶颈。 |
| 模型小／可训练参数少与显存极低 | 模型权重、激活、优化器、视觉输入与动作头共同决定占用，需按配置实测。 |
| 未见物体／家庭与全新运动技能 | 测试中某一因素未见，不等于所有知识都未见，也不保证学会全新控制技能。 |
| 成功率与阶段进度分数 | 一些实机结果按子阶段计分；不能直接与整任务二值成功率等同。 |

## 六、与你当前候选课题的对应关系

- **OpenVLA-OFT**：候选实验底座，固定模型、动作块与L1目标。
- **LIBERO**：候选任务和闭环评测环境。
- **LIBERO-Plus**：借鉴扰动定义、对照与可靠性诊断；阅读它不要求首轮复现全套基准。
- **LoRA**：候选适配工具。
- **ACT／Diffusion Policy／π₀**：帮助理解动作块、执行延迟和连续动作分布。
- **RT-2／OpenVLA／OXE／Octo／FAST／π₀.₅／SmolVLA**：定位语义、数据、生成方式与效率的不同研究切口。

## 七、用一分钟检查自己是否读懂

选任意一篇，合上文件，说出：“它要解决什么；输入输出是什么；相较前人改了哪里；哪张图支持；哪种情况不能据此下结论。”
